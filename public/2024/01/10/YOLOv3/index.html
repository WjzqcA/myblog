YOLOv3

YOLOv3

一、采用 Darknet-53 使用残差连接

YOLOv3 采用新的骨干网络 Darknet-53（使用前 52 层，不含全连接层），为全卷积网络，无池化层和全连接层，广泛使用残差连接。为降低池化带来的梯度负面效应，YOLOv3 通过卷积核步长（stride=2）实现特征图下采样（边长减半）。与 YOLOv2 类似，骨干网络对输入图像进行 32 倍下采样，输入图像尺寸需为 32 的倍数。

图中一个 Convolutional 包含卷积层、BN 层和 LeakyReLU 层。Residual 为残差结构，将上层卷积结果与框内最后一个卷积输出拼接。

二、多尺度特征图

YOLOv2 使用 passthrough 层融合细粒度特征以提升小目标检测。YOLOv3 采用 FPN（特征金字塔网络）增强多尺度融合，在不同尺度特征图上独立检测：小尺寸特征图检测大物体，大尺寸特征图检测小物体，显著提升小目标检测效果（大尺度特征图 grid cell 较多，感受野较小，适合小目标）。

FPN 左侧通过编码下采样，右侧进行二倍上采样，并将同尺度特征图在通道维度拼接（YOLO 中为拼接而非相加），中间加一层卷积统一通道数。拼接后，再通过 3x3 卷积生成最终预测特征图。

三、Anchor 计算（与 YOLOv2 类似）

使用 K-Means 聚类为每个尺度特征图生成 3 个 anchor。训练时，因输出三尺度特征图，真实标签需处理为三尺度张量以监督输出。

tx、ty、tw、th 为回归的平移缩放参数，通过公式计算 bx、by、bw、bh（预测的相对位置和宽高），与真实值进行梯度下降。cx、cy 为当前 grid cell 左上角坐标。

四、损失函数

损失函数在 S 个网格、每个网格 B 个 bbox 上计算。1obj 表示当前网格是否包含 GT box 中心点（含为 1，否则为 0），1nobj 相反。λcoord 和 λnoobj 为损失权重系数，论文中设为 5 和 0.5。损失在不同尺度特征图上计算后相加。

Bbox 损失：xy 使用二类交叉熵损失，wh 使用平方误差。YOLOv3 不再仅由中心点所在 grid cell 预测，而是选择 anchor 与 GT 的 IoU 最大者作为正样本，IoU 超过阈值但非最大者丢弃，未达阈值为负样本（或将所有大于阈值的 anchor 作为正样本以平衡样本量）。

xi拔为真实标签（YOLOv2 中为 IoU 值，YOLOv3 中为 0 或 1），xi 为预测值。置信度损失使用二类交叉熵，分别计算正样本（含物体）和负样本（不含物体）的损失。

五、测试阶段

  1. 输入预处理：测试图像调整为模型输入尺寸并归一化。
  2. 前向传播：输入 YOLOv3 模型，各尺度特征图预测边界框。
  3. 解码和后处理：解码模型输出，获取边界框坐标和类别概率，应用非极大值抑制（NMS）过滤重叠框。
  4. 多尺度融合：缩放不同尺度检测结果并合并。
  5. 得分筛选：根据综合得分保留最终检测结果。
  6. 结果输出：输出目标的类别、位置和置信度，用于可视化或应用。
